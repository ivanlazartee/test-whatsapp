# ¿Cuánto tiempo perdés contestando WhatsApp?

Test de 6 preguntas de **NorteDigitalDev** para dueños de negocios. Calcula las horas por mes que se van en responder consultas por WhatsApp, muestra cuántas son preguntas repetidas y recomienda qué herramienta digital ayudaría según el rubro. Al final ofrece un diagnóstico gratis por WhatsApp.

## Tecnologías

- HTML, CSS y JavaScript puro (sin dependencias)
- Tipografía: Archivo (Google Fonts)

## Cómo verlo

Abrí `index.html` en el navegador o usá **Live Server** en VS Code.

## Configuración

El número de WhatsApp y el usuario de Instagram están al principio de `js/app.js`.
